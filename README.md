## 🌈 What is PrismOS?

<p align="center">
  <img src="assets/what-is-prismos.png" width="80%" alt="PrismOS Explanation" />
</p>

> **PrismOS** is a magical bridge that lets your Apple Silicon Mac run Linux — safely and beautifully.  
> Think of it as the translator between Apple hardware and open-source freedom 🧠🐧🍎

## ✨ Key Features (Icon Grid)

| 💎 | Feature | Description |
|----|----------|-------------|
| ⚡ | **One-Line Install** | Installs via one command in Terminal. |
| 🛡️ | **Safe & Non-Destructive** | Installs beside macOS — no data loss. |
| 🧬 | **Apple Silicon Smart** | Supports M1 → M4 chips. |
| 📶 | **Auto Firmware Extraction** | Wi-Fi & Bluetooth just work. |
| 🧰 | **Beginner Friendly** | Guided interface — no guesswork. |
